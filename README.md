# 直播台安装包

直播台 macOS 播放器的公开安装包与自动更新仓库，源码仓库保持私密。

- 最新版本：[Releases](https://github.com/suyun888/maclive-player-releases/releases/latest)
- 直接下载：[MacLive-0.11.14-arm64.zip](https://github.com/suyun888/maclive-player-releases/releases/download/v0.11.14/MacLive-0.11.14-arm64.zip)
- 安装包为 arm64 构建，要求 macOS 13 或更新版本。
- 安装包不包含订阅地址、服务器地址或任何个人配置。
- 应用内自动更新会读取本仓库的最新 Release，无需 GitHub 账号。
